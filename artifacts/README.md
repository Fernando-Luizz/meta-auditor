# Supplementary artifacts

Evidence and evaluation material supporting the Meta-Auditor paper. Everything here is frozen: it reflects the exact tool outputs and reports discussed in the paper, not the current state of a live audit.

| Directory | Contents |
|---|---|
| [`normalization/`](normalization/README.md) | Specification of the 80 deterministic normalization mappings (42 Lighthouse + 38 WAVE, 71 normalized barrier types) |
| [`technical-evaluation/`](technical-evaluation/README.md) | Raw tool outputs, consolidated JSON, and HTML/PDF reports for the nine technical-evaluation cases (CP01-CP09) |
| [`acceptance-evaluation/`](acceptance-evaluation/README.md) | Pseudonymized reports used in the five-participant acceptance evaluation (AP01-AP05) |
| [`TAM mapping/`](TAM%20mapping/README.md) | Pseudonymized mapping of the open-ended TAM responses cited in the paper |
| `Article images/` | Figures used in the paper: architecture, normalization, consolidation, report layout, results |
