# Technical Evaluation Artifacts

## Artifact organization

The technical evaluation contains nine cases, identified as CP01–CP09.

Each case directory contains:

- the raw Lighthouse JSON response;
- the raw WAVE JSON response;
- the consolidated Meta-Auditor JSON;
- the generated HTML report;
- the generated PDF report.

Together, the nine directories provide the complete material used in the
technical evaluation reported in the associated article.
