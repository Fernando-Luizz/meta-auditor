# Acceptance Evaluation Reports

This directory contains the public versions of the five reports used
in the acceptance evaluation, identified as AP01–AP05.

Each case is available in HTML and PDF. Both formats present the same
audit results.

The primary identification of each institutional context, including
the audited URL, collection date and internal audit identifier, was
removed. Visual and semantic evidence generated by the Meta-Auditor
was preserved to maintain the integrity of the reports evaluated by
the participants. Consequently, some evidence may contain fragments
of the original portal content.

Selected pseudonymized excerpts from the open-ended questionnaire
responses are available in the `TAM mapping` directory to support
traceability of the qualitative analysis. Closed-question raw data
and personally identifying information are not included.
