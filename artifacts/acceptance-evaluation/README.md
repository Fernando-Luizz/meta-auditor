# Acceptance evaluation reports

Public, pseudonymized versions of the five reports used in the acceptance evaluation (AP01-AP05), each available as HTML and PDF with identical audit results.

**Removed:** the institutional context of each case, including the audited URL, collection date, and internal audit identifier.

**Preserved:** the visual and semantic evidence Meta-Auditor generated for each report, to keep intact the material participants actually evaluated. Because of this, some evidence may still contain fragments of the original portal content.

Selected, pseudonymized excerpts from the open-ended questionnaire responses are in [`../TAM mapping/`](../TAM%20mapping/README.md), to support traceability of the qualitative analysis in the paper. Closed-question raw data and any personally identifying information are not included.
